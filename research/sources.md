# Research Sources

## Source 1

Title: FastAPI Documentation

URL: https://fastapi.tiangolo.com/

FastAPI is a Python web framework for building APIs.

FastAPI uses Python type hints and provides tools for
defining API endpoints and automatically generating
interactive API documentation.

## Source 2

Title: MDN HTTP Overview

URL: https://developer.mozilla.org/en-US/docs/Web/HTTP

HTTP is an application-layer protocol used for communication
between clients and servers.

HTTP defines methods such as GET, POST, PUT, and DELETE.

## Source 3

Title: REST Architectural Style

REST is an architectural style for distributed systems.

REST APIs commonly expose resources through URLs and use
HTTP methods to operate on those resources.
